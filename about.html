About ELEMENTA

Exploring the elements beyond the ordinary.

ELEMENTA is an interactive educational platform designed to make learning the periodic table more engaging, intuitive, and immersive.

Instead of presenting chemical elements as static information on a chart, ELEMENTA brings them to life through interactive exploration, visual representations, and gesture-based interaction.

What I Built

  • Interactive Periodic Table: Explore chemical elements and access their individual information.
  • Element Profiles: Discover atomic numbers, symbols, atomic masses, classifications, and other important properties.
  • Atomic Models: Visual representations that help make atomic structures easier to understand.
  • Rare Elements Explorer: Discover rare and less commonly discussed elements.
  • Category Classification: Explore elements based on their chemical families and properties.
  • KIANA — Gesture-Controlled Interface: An experimental interface that uses webcam-based hand tracking to make exploration possible through hand gestures.

Meet KIANA

KIANA is the gesture-controlled interaction system developed as part of ELEMENTA.

Using a webcam and hand-landmark detection, KIANA allows users to interact with the periodic table through gestures.

  • Moving a virtual cursor using hand movements.
  • Selecting elements through pinch gestures.
  • Scrolling through elements using hand movements.
  • Expanding and collapsing the discovery interface using both hands.

The system is designed around gesture-first interaction while retaining a mouse-based fallback.

Technology Behind ELEMENTA

  • HTML
  • CSS
  • JavaScript
  • MediaPipe Hand Landmarker
  • Webcam-based hand tracking

The Vision

The goal of ELEMENTA is simple: make scientific exploration feel less like reading a textbook and more like interacting with the subject itself.

This project is an ongoing exploration of how technology can transform the way we learn, discover, and interact with scientific information.
